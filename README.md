# Projeto - Banco de Dados para Academia

## Integrantes

- Bruno Silveira
- Felipe Lamy Rosa Rennó
- Yuri Guimenti Chiarini de Faria

## Tema

Sistema de Gerenciamento de Academia

## Descrição

O projeto consiste no desenvolvimento de um banco de dados para o gerenciamento de uma academia.

O sistema permite organizar informações sobre alunos, professores, planos, fichas de treino, treinos e exercícios, além de representar os relacionamentos existentes entre essas informações.

O modelo desenvolvido contempla relacionamentos 1:1, 1:N, N:M e um relacionamento recursivo entre professores.
